#  Repo is intended to deep dive core DSA fundamentals
Problems are grouped under their respective subtopic, in order to focus on repeatedly applying common patterns rather than randomly tackling questions.

**Fundamentals**

To find the greatest amount of success when practicing, it is highly recommended to know the methods and runtimes of the following 
data structures and their operations:

* Arrays
* Maps
* Binary Search
* Linked Lists
* Queues
* Heaps and Priority Queues
* Stacks
* Trees and Binary Trees
* Graphs(BFS/DFS)
* Backtracking
* Sorting
* Dynamic Programming
